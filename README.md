# YouTube Watch History Analyzer

A fast and statistical Python script to estimate your total YouTube watch hours grouped by years using Google Takeout data. It bypasses the need to scrape thousands of videos by using statistical sampling and concurrent processing.

## Setup
1. Git clone:
   ```bash
   git clone https://github.com/Zsenpai/YT-TR.git
   ```
2. Download your YouTube watch history from Google Takeout (`سجل المشاهدة.html` or `watch-history.html`) and place it in the project folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4.Run the script:
   ```bash
   python3 script.py
   ```
