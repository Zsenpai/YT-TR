# YouTube Watch History Analyzer

A fast and statistical Python script to estimate your total YouTube watch hours grouped by years using Google Takeout data. It bypasses the need to scrape thousands of videos by using statistical sampling and concurrent processing.

## Setup
1. Download your YouTube watch history from Google Takeout (`سجل المشاهدة.html` or `watch-history.html`) and place it in the project folder.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
